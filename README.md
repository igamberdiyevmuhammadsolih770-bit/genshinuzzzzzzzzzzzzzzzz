# Genshin UZ

O‘zbekcha norasmiy Genshin portali.

## Kompyuterda ishga tushirish

Node.js 22.13 yoki yangiroq versiyasini o‘rnating.

```sh
npm install
npm run dev
```

## Vercel

ZIPni oching va shu papkani loyiha ildizi sifatida ulang. Qurish buyrug‘i: `npm run build:vercel`. Natija papkasi: `vercel-dist`. `vercel.json` bularni avtomatik belgilaydi. API ishlashi uchun loyiha to‘liq yuklanishi kerak. Yangiliklar uchun Vercel muhitiga `GEMINI_API_KEY` va `GEMINI_MODEL=gemini-3.5-flash-lite` qo‘shing. Kalit bu ZIP ichiga kiritilmagan. Tafsilotlar: VERCEL-UZ.md.

UID qidiruvi faqat ommaga ochiq profil va ko‘rgazmani ko‘rsatadi. Vercel funksiyasi sun’iy javoblar bilan tekshirilgan; haqiqiy Vercel muhitidagi tashqi xizmat javobi tasdiqlanmagan. To‘liq inventarga kirish imkoni yo‘q.

Ranglar menyusida to‘rtta mavzu bor. Tanlov va bajarilgan missiyalar qurilmada saqlanadi.

## Ma’lumotlar va tarjima

2578 ta missiya nomi va 4504 ta maqsad o‘zbekchaga tarjima qilingan. Atoqli nomlar saqlanadi. AI tarjimasida noaniqlik bo‘lishi mumkin. Tekshirilgan o‘zbekcha qo‘llanmalar alohida ko‘rsatiladi. Tasvirlar bevosita missiya, personaj, bob yoki hududga oidligi bilan belgilangan. Barcha tasvirlar aynan o‘sha missiya skrinshoti emas.

O‘yin, musiqa va tasvirlarning huquqlari HoYoverse hamda tegishli mualliflarga tegishli. Manbalar rasm indekslari va kataloglarda saqlangan.
